# Myer - Personal Finance Management System

## Product Vision
Web-based sistem untuk mengelola keuangan pribadi secara terstruktur, akurat, dan berbasis data.

## Problem Statement
- Tidak konsisten mencatat keuangan
- Tidak tahu ke mana uang pergi
- Tidak ada kontrol pengeluaran
- Tidak ada insight finansial

## Solution
- Pencatatan transaksi terstruktur
- Pengelolaan akun terpusat
- Budgeting per kategori
- Dashboard real-time
- Laporan analisis

## Target User
- Individu (pelajar, pekerja)
- Freelancer/UMKM (future)

## Core Value
- **Clarity**: Tahu kondisi keuangan
- **Control**: Kendali pengeluaran  
- **Insight**: Analisis data
- **Structure**: Sistem rapi

## Scope (MVP)
✅ **In Scope**
- Auth
- Account/Category/Transaction
- Dashboard/Budget/Report

❌ **Out of Scope**
- Bank API
- AI/ML
- Multi-user
- Mobile native

## Goals
| Jangka | Target |
|--------|--------|
| Short | MVP stabil |
| Mid | Budget/Report lengkap |
| Long | SaaS scalable |

## Success Metrics
- Catat transaksi <5 detik
- Dashboard load <2 detik
- Akurasi 100%
- Retensi pengguna

## Tech Stack
- Laravel (Backend)
- Tailwind (UI)
- MySQL (Database)

## Quick Start
```bash
composer install
php artisan migrate
php artisan serve
```
